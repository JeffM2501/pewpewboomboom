# Coding Style Rules

## C++ Style Guidelines

- **Brace Placement**: Do not place the opening brace `{` on the same line as class declarations, structure declarations, function definitions, control flow statements, or any other declarations. Always place the opening brace `{` on its own line.
  
  *Example:*
  ```cpp
  class MyClass
  {
      // ...
  };

  void MyFunction()
  {
      // ...
  }
  ```

- **Line Length**: Do not restrict C++ code lines to an 80-character limit. Avoid wrapping parameters or expressions onto multiple lines purely to fit inside a narrow column limit.
